Here's a well-structured Python program that checks whether a given number is **prime**. The program includes both a function to determine primality and a simple user interface to take input and display the result.

---

### ✅ **Python Program to Check if a Number is Prime**

```python
import math

def is_prime(n):
    """
    Check if a number is prime.
    
    Args:
        n (int): The number to check.
        
    Returns:
        bool: True if the number is prime, False otherwise.
    """
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    # Check for divisors up to the square root of n
    max_divisor = int(math.sqrt(n)) + 1
    for i in range(3, max_divisor, 2):
        if n % i == 0:
            return False
    return True

def main():
    """
    Main function to take user input and display the result.
    """
    try:
        num = int(input("Enter a number: "))
        if is_prime(num):
            print(f"{num} is a prime number.")
        else:
            print(f"{num} is not a prime number.")
    except ValueError:
        print("Please enter a valid integer.")

if __name__ == "__main__":
    main()
```

---

### 🔍 **How It Works**

1. **Prime Definition**: A prime number is a number greater than 1 that has no divisors other than 1 and itself.
2. **Special Cases**:
   - Numbers less than or equal to 1 are **not prime**.
   - 2 is the **only even prime number**.
3. **Efficient Check**:
   - Only check for divisors up to the **square root** of the number (inclusive).
   - Skip even numbers after checking 2, as even numbers greater than 2 are **not prime**.
